A tour ends when the user finishes the last step, or leaves early with the close button, the <kbd>Escape</kbd> key or a click on the overlay. You can step in before it closes, find out which way it ended, and let the user pick it up again later.

## Confirm on Exit

`onDestroyStarted` runs when the tour is about to end. Once you set it, the tour only ends when you call `destroy()`. The example asks only when the user leaves early.

<CodeSample
  heading={'Confirm on Exit'}
  config={{
    animate: true,
    showProgress: true,
  }}
  tour={[
    { element: '.line:nth-child(9)', popover: { title: 'Try to Leave', description: 'Press Escape, the close button or the dimmed page. This hook asks before the tour ends.', side: "bottom", align: 'start' }},
    { element: '.line:nth-child(10)', popover: { title: 'Finishing Is Fine', description: 'The reason is "done" when the user finishes the tour, so there is no question then.', side: "bottom", align: 'start' }},
    { popover: { title: 'Last Step', description: 'Press Done to finish without a question, or close it to get one.' } }
  ]}
  id={"confirm-destroy"}
  client:load>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    steps: [
      { element: "#search", popover: { title: "Search", description: "Find anything." } },
      { element: "#export", popover: { title: "Export", description: "Download a CSV." } },
    ],
    onDestroyStarted: (element, step, { reason }) => {
      if (reason === "done" || confirm("Are you sure?")) {
        driverObj.destroy();
      }
    },
  });

  driverObj.drive();
  ```
</CodeSample>

## Prevent Exit

`allowClose: false` removes the close button and turns off Escape and overlay clicks, so the only way out is to finish the tour.

<CodeSample
  heading={'Prevent Exit'}
  config={{
    animate: true,
    showProgress: true,
    allowClose: false,
  }}
  tour={[
    { element: '.line:nth-child(5)', popover: { title: 'No Way Out', description: 'There is no close button, and Escape and clicks on the dimmed page do nothing.', side: "bottom", align: 'start' }},
    { popover: { title: 'Last Step', description: 'Press Done to finish the tour.' } }
  ]}
  id={"prevent-exit"}
  client:load>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    allowClose: false,
    steps: [
      { element: "#search", popover: { title: "Search", description: "Find anything." } },
      { element: "#export", popover: { title: "Export", description: "Download a CSV." } },
    ],
  });

  driverObj.drive();
  ```
</CodeSample>

To keep the close button and only ignore clicks on the overlay, use `overlayClickBehavior: "none"` instead.

## Finished or Closed

`onDestroyStarted` and `onDestroyed` get a `reason`:

- `"done"`: the user moved past the last step
- `"close"`, `"escape"` or `"overlay"`: the user left early
- `"replaced"`: another tour or highlight started
- `"api"`: your code called `destroy()`

Use it to mark onboarding complete only when the user finished it, or to log where users drop off. Finish the tour below, or leave it early.

<CodeSample
  heading={'Track Completion'}
  config={{
    animate: true,
    showProgress: true,
  }}
  tour={[
    { element: '#destroy-reason', popover: { title: 'Finish or Leave', description: 'Finish this tour, or leave it any way you like: close button, Escape or a click outside.', side: "left", align: 'start' }},
    { element: '.line:nth-child(8)', popover: { title: 'Why It Ended', description: 'onDestroyed gets the reason and the index of the step the user was on.', side: "bottom", align: 'start' }},
    { popover: { title: 'Last Step', description: 'Press Done to finish, or close it now to see the difference.' } }
  ]}
  id={"destroy-reason"}
  client:load>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    steps: [
      // ...
    ],
    onDestroyed: (element, step, { reason, index }) => {
      if (reason === "done") {
        markOnboardingComplete();
      } else {
        trackDropOff({ reason, step: index });
      }
    },
  });

  driverObj.drive();
  ```
</CodeSample>

A `destroy()` you call from a hook keeps the reason of the user action that started it. In [Confirm on Exit](#confirm-on-exit), `onDestroyed` gets `"close"`, not `"api"`.

## Resume a Tour

`onDestroyed` also gets the `index` of the step the user was on. Save it when they leave early, and pass it to `drive()` next time. Close the tour below on any step, then start it again.

<InteractiveSample scenario="resume" client:load>
  ```js
  const STEP_KEY = "tour-step";

  const driverObj = driver({
    showProgress: true,
    steps: [
      { element: "#overview", popover: { title: "Overview" } },
      { element: "#reports", popover: { title: "Reports" } },
      { element: "#team", popover: { title: "Team" } },
      { element: "#settings", popover: { title: "Settings" } },
    ],
    onDestroyed: (element, step, { reason, index }) => {
      if (reason === "done") {
        localStorage.removeItem(STEP_KEY);
      } else {
        localStorage.setItem(STEP_KEY, String(index));
      }
    },
  });

  driverObj.drive(Number(localStorage.getItem(STEP_KEY) ?? 0));
  ```
</InteractiveSample>

For a tour that continues on another page, see [Multi-Page Tours](/docs/interactive-tours#multi-page-tours).
