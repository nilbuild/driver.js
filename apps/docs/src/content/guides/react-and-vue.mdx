Driver.js works on plain DOM elements, so it needs no wrapper. Create the driver once the elements are on the page, and destroy it when the component goes away.

## React

```jsx
import { useEffect, useRef } from "react";
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

export function Dashboard() {
  const driverRef = useRef(null);

  useEffect(() => {
    driverRef.current = driver({
      steps: [
        { element: "#new-project", popover: { title: "New" } },
        { element: "#invite", popover: { title: "Invite" } },
      ],
    });

    return () => driverRef.current.destroy();
  }, []);

  return (
    <header>
      <button id="new-project">New project</button>
      <button id="invite">Invite</button>
      <button onClick={() => driverRef.current.drive()}>
        Take the tour
      </button>
    </header>
  );
}
```

## Vue

```vue
<script setup>
import { onBeforeUnmount } from "vue";
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

const driverObj = driver({
  steps: [
    { element: "#new-project", popover: { title: "New" } },
    { element: "#invite", popover: { title: "Invite" } },
  ],
});

onBeforeUnmount(() => driverObj.destroy());
</script>

<template>
  <header>
    <button id="new-project">New project</button>
    <button id="invite">Invite</button>
    <button @click="driverObj.drive()">Take the tour</button>
  </header>
</template>
```

## Next.js

A tour runs in the browser, so put it in a client component. Importing `driver.js` when the tour starts keeps it out of the server render and out of the page's first load.

```tsx
"use client";

import { useEffect, useRef } from "react";
import type { Driver } from "driver.js";
import "driver.js/dist/driver.css";

export function TourButton() {
  const driverRef = useRef<Driver | null>(null);

  useEffect(() => {
    return () => driverRef.current?.destroy();
  }, []);

  async function startTour() {
    const { driver } = await import("driver.js");

    driverRef.current = driver({
      steps: [
        { element: "#new-project", popover: { title: "New" } },
        { element: "#invite", popover: { title: "Invite" } },
      ],
    });
    driverRef.current.drive();
  }

  return <button onClick={startTour}>Take the tour</button>;
}
```

With the Pages Router, the same component works as is. To start a tour on load instead of on a click, call `startTour()` from the `useEffect`.

## Good to Know

- A step's `element` is looked up when the step starts, so selectors can point at elements that render later.
- When your framework replaces a highlighted element, the step [follows the new one](/docs/interactive-tours#elements-that-re-render).
- Prefer selectors over refs in steps: a selector finds the new element after a re-render, a stored element doesn't.

**Uses**: [`driver()`](/docs/configuration), [`drive()` and `destroy()`](/docs/api#starting-and-stopping)
