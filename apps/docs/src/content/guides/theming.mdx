Driver.js is styled with plain CSS. Override its classes, set its CSS variables, or change the popover's DOM in a hook.

## Popover

Give the popover your own class with `popoverClass`, then style it. Set it on the driver for every popover, or on a step's `popover` for one.

<CodeSample
  buttonText={"Driver.js Website Theme"}
  config={{
    prevBtnText: '&larr; Previous',
    nextBtnText: 'Next &rarr;',
    doneBtnText: 'Done',
    showButtons: ['next', 'previous'],
    popoverClass: 'driverjs-theme'
  }}
  tour={[
    { element: '#demo-theme', popover: { title: 'Style However You Want', description: 'This popover carries the driverjs-theme class.', side: 'left', align: 'start' } },
    { element: '.line:nth-child(5)', popover: { title: 'One Option', description: 'popoverClass adds the class. The CSS below does the rest.', side: 'bottom', align: 'start' } },
  ]}
  id={"demo-theme"}
  client:load
>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    popoverClass: "driverjs-theme",
    steps: [
      // ...
    ],
  });

  driverObj.drive();
  ```
</CodeSample>

### Popover Classes

```css
.driver-popover {}                 /* The popover */
.driver-popover-arrow {}           /* The arrow pointing at the element */
.driver-popover-title {}
.driver-popover-description {}
.driver-popover-close-btn {}       /* The close button in the top right corner */

.driver-popover-footer {}          /* Holds the progress text and the buttons */
.driver-popover-progress-text {}
.driver-popover-navigation-btns {} /* Holds the buttons */
.driver-popover-footer-btn {}      /* Shared look of the buttons. Add it to your own buttons */
.driver-popover-prev-btn {}
.driver-popover-next-btn {}
.driver-popover-done-btn {}        /* Also on the next button on the last step */
.driver-popover-btn-disabled {}    /* On a disabled button */

/* Where the popover ended up, after flipping to fit the screen */
.driver-popover-side-top {}        /* or -right, -bottom, -left */
.driver-popover-align-start {}     /* or -center, -end */

/* Action steps */
.driver-popover-has-instruction {} /* On the popover of an action step */
.driver-popover-instruction {}     /* The instruction row */
.driver-popover-instruction-text {}       /* Its text */
.driver-popover-instruction-indicator {}  /* The dot at its end; a check mark once done */
.driver-popover-instruction-done {}       /* On the popover while it pauses for advanceDelay */
.driver-popover-btn-disabled[aria-disabled] {}  /* Next while the step waits for the user */
.driver-popover-feedback {}        /* The line shown by nudge("...") */

/* States */
.driver-popover-waiting {}         /* On the popover while it waits for an element */
.driver-popover-nudge {}           /* On the popover while nudge() shakes it */
```

### CSS Variables

Set them on `:root`, or on your `popoverClass` to scope them.

```css
:root {
  /* Font of the popover, and of checklists */
  --driver-popover-font-family: "Inter", sans-serif;

  /* Action steps: the instruction row */
  --driver-instruction-background: #f2f2f2;
  --driver-instruction-color: inherit;
  --driver-instruction-padding: 8px 10px;
  --driver-instruction-radius: 4px;

  /* Action steps: the dot at the end of the row, and the disabled Next */
  --driver-instruction-indicator-color: #f59e0b;
  --driver-instruction-indicator-size: 8px;
  --driver-instruction-next-color: #a3a3a3;

  /* Action steps: the done state, for the row, the check mark and Next */
  --driver-instruction-done-background: #dcfce7;
  --driver-instruction-done-color: #15803d;

  /* The line shown by nudge("...") */
  --driver-feedback-color: #b45309;

  /* The shake of nudge(), and the flash shown instead with reduced motion */
  --driver-nudge-distance: 6px;
  --driver-nudge-duration: 500ms;
  --driver-nudge-color: #f59e0b;

  /* Stacking of allowedElements above the overlay */
  --driver-allowed-z-index: 10001;
}
```

The values above are the defaults, except the font. Its default is:

```css
"Helvetica Neue", Inter, ui-sans-serif, "Apple Color Emoji", Helvetica, Arial, sans-serif;
```

### Action Steps

An [action step](/docs/action-driven-tours#make-the-user-act) shows an instruction row that ends in a pulsing dot, and a Next button that looks disabled until the user has done it. While the step pauses for `advanceDelay` the dot becomes a check mark and the row and Next turn green. The dot and the check are drawn in CSS, don't animate with `prefers-reduced-motion`, and are hidden from screen readers. The variables cover the colors and sizes, and the classes the rest.

<ActionDrivenSample scenario="themed" client:load>
  ```js
  const driverObj = driver({
    popoverClass: "my-theme",
    showButtons: ["next", "close"],
    steps: [
      {
        element: "#publish",
        advanceOn: "click",
        advanceDelay: 1200,
        popover: {
          title: "Publish the page",
          instruction: "Click <b>Publish</b>.",
        },
      },
      // ...
    ],
  });

  driverObj.drive();
  ```
</ActionDrivenSample>

```css
.my-theme {
  --driver-instruction-background: #eef2ff;
  --driver-instruction-color: #3730a3;
  --driver-instruction-radius: 999px;
  --driver-instruction-padding: 8px 14px;
  --driver-instruction-indicator-color: #6366f1;
  --driver-instruction-indicator-size: 10px;
  --driver-instruction-done-background: #dcfce7;
  --driver-instruction-done-color: #166534;
}

.my-theme.driver-popover-instruction-done .driver-popover-instruction {
  font-weight: 600;
}
```

To drop the dot and the check, hide the indicator. To change the row altogether, replace the content of `popover.instruction` in [`onPopoverRender`](#changing-the-popover-dom); driver.js leaves it alone from then on. `popover.instructionIndicator` is the dot itself.

```css
.driver-popover-instruction-indicator {
  display: none;
}
```

### Changing the Popover DOM

`onPopoverRender` gets the popover's elements before it shows. Add, move or change anything. See [Custom Buttons](/docs/popover#custom-buttons) for a live example.

```typescript
type PopoverDOM = {
  wrapper: HTMLElement;
  arrow: HTMLElement;
  title: HTMLElement;
  description: HTMLElement;
  footer: HTMLElement;
  progress: HTMLElement;
  previousButton: HTMLButtonElement;
  nextButton: HTMLButtonElement;
  closeButton: HTMLButtonElement;
  footerButtons: HTMLElement;

  // Only on steps with popover.instruction: the row, and the indicator at
  // its end.
  instruction?: HTMLElement;
  instructionIndicator?: HTMLElement;

  // Only after nudge("...") showed a message
  feedback?: HTMLElement;
};
```

```js
const driverObj = driver({
  onPopoverRender: popover => {
    const link = document.createElement("a");
    link.href = "/help/tours";
    link.textContent = "Learn more";
    popover.description.append(" ", link);
  },
});
```

## Overlay

`overlayColor` takes any CSS color and `overlayOpacity` a number from 0 to 1. The defaults are `"#000"` and `0.7`.

```js
const driverObj = driver({
  overlayColor: "red",
  overlayOpacity: 0.3,
});

driverObj.highlight({
  popover: { title: "A red overlay", description: "Any CSS color works." },
});
```

## Hints

Hint popovers are regular popovers, so everything above applies. The beacons read two variables, set on `.driver-hint` or on a class you pass as `beacon.className`:

```css
.driver-hint {
  --driver-hint-size: 32px;
  --driver-hint-color: #e11d48;
}
```

See [Styling Hints](/docs/hints#styling) for live examples.

## Checklist

[Checklists](/docs/checklists) have their own stylesheet and classes.

`--driver-checklist-color` colors the progress bar, the ticks and the focus rings.

### Custom Theme

Pass `className` to put your own class on the widget, then style its parts. This is the theme of the driver.js homepage:

<ChecklistSample
  idPrefix="styling-checklist-theme"
  buttonText="Themed Checklist"
  config={{ className: "checklist-brutalist" }}
  client:load

```js
checklist({
  id: "onboarding",
  className: "checklist-brutalist",
  items,
});
```

Its CSS, and more themes to copy, are on the [Checklist Themes](/docs/checklist-themes) page.

```css
.driver-checklist-launcher-count {}   /* "1/4" */

.driver-checklist-progress {}
.driver-checklist-progress-bar {}

.driver-checklist-progress-text {}    /* "1 of 4" */

.driver-checklist-items {}
.driver-checklist-item {}
.driver-checklist-item-done {}        /* Added to an item once it is done */

.driver-checklist-item-trigger {}     /* The item's link, button or plain row */
.driver-checklist-item-title {}
.driver-checklist-item-description {}
```

The widget also reads these variables:

```css
.driver-checklist {
  --driver-checklist-offset-x: 20px; /* Distance from the screen edges */
  --driver-checklist-offset-y: 20px;
}
```

It sets `--driver-checklist-progress` to the progress as a percentage, for progress drawn in CSS like the [progress ring](/docs/checklist-themes#progress-ring). The font follows `--driver-popover-font-family`.
