Driver.js does three things: tours, single highlights and hints. Each starts with a few lines.

## A Tour

Pass `steps` to `driver()` and call `drive()`. Each step points at an element and describes it in a popover.

<CodeSample
  heading={'Basic Tour'}
  config={{
    showProgress: true,
  }}
  tour={[
    { element: '#tour-example pre', popover: { title: 'Highlight Anything', description: 'A step can point at any element on the page.' }},
    { element: '#tour-example code .line:first-child', popover: { title: 'Import the Library', description: 'One import for the code.' }},
    { element: '#tour-example code .line:nth-child(2)', popover: { title: 'Import the Styles', description: 'And one for the stylesheet.' }},
    { popover: { title: 'No Element Needed', description: 'A step without an element shows in the middle of the screen. Use the arrow keys to move, Escape to close.' }},
  ]}
  id={"tour-example"}
  client:load
>
```js
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

const driverObj = driver({
  showProgress: true,
  steps: [
    {
      element: ".page-header",
      popover: {
        title: "Header",
        description: "Search and account live here.",
      },
    },
    {
      element: ".sidebar",
      popover: { title: "Sidebar" },
    },
    { popover: { title: "That's it" } },
  ],
});

driverObj.drive();
```
</CodeSample>

More in [Tour Basics](/docs/tour-basics). To make steps wait for the user, see [Interactive Tours](/docs/interactive-tours) and [Action-Driven Tours](/docs/action-driven-tours).

## A Single Highlight

`highlight()` takes one step and shows it on its own, without navigation buttons.

<CodeSample heading='Highlight an Element' id={"some-element"} highlight={{
  element: '#some-element',
  popover: {
    title: 'Title for the Popover',
    description: 'Description for it',
  },
}} client:load>
```js
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

const driverObj = driver();

driverObj.highlight({
  element: "#some-element",
  popover: {
    title: "Title for the Popover",
    description: "Description for it",
  },
});
```
</CodeSample>

More in [Simple Highlight](/docs/simple-highlight).

## Hints

Hints are pulsing beacons that open a popover when clicked. There is no overlay and the page stays usable. They come from their own entry.

<HintsSample
  idPrefix="basic"
  buttonText="Show Hints"
  hints={[
    {
      element: "#basic-export",
      id: "export",
      popover: {
        title: "Export your data",
        description: "Download this report as CSV or PDF.",
      },
    },
    {
      element: "#basic-summary",
      id: "summary",
      beacon: { side: "left", align: "center" },
      popover: {
        title: "Auto-generated summary",
        description: "This paragraph is written for you from the quarter's numbers.",
        side: "bottom",
      },
    },
  ]}
  client:load
/>

```js
import { hints } from "driver.js/hints";
import "driver.js/dist/hints.css";

const productHints = hints({
  hints: [
    {
      element: "#export-btn",
      popover: { title: "Export your data", description: "Download this report as CSV or PDF." },
    },
    {
      element: "#summary",
      popover: { title: "Auto-generated summary", description: "Written for you from the numbers." },
    },
  ],
});

productHints.show();
```

More in the [Hints guide](/docs/hints). For onboarding task lists, see [Checklists](/docs/checklists).

## With a Framework

Driver.js works on plain DOM elements, so it needs no wrapper. Create the driver once the elements are on the page, and destroy it when the component goes away.

React:

```jsx
import { useEffect, useRef } from "react";
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

export function Dashboard() {
  const driverRef = useRef(null);

  useEffect(() => {
    driverRef.current = driver({
      steps: [
        { element: "#new-project", popover: { title: "New project", description: "Start here." } },
        { element: "#invite", popover: { title: "Invite", description: "Bring your team." } },
      ],
    });

    return () => driverRef.current.destroy();
  }, []);

  return (
    <header>
      <button id="new-project">New project</button>
      <button id="invite">Invite</button>
      <button onClick={() => driverRef.current.drive()}>Take the tour</button>
    </header>
  );
}
```

Vue:

```vue
<script setup>
import { onBeforeUnmount } from "vue";
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

const driverObj = driver({
  steps: [
    { element: "#new-project", popover: { title: "New project", description: "Start here." } },
    { element: "#invite", popover: { title: "Invite", description: "Bring your team." } },
  ],
});

onBeforeUnmount(() => driverObj.destroy());
</script>

<template>
  <header>
    <button id="new-project">New project</button>
    <button id="invite">Invite</button>
    <button @click="driverObj.drive()">Take the tour</button>
  </header>
</template>
```

A step's `element` is looked up when the step starts, so selectors can point at elements that render later. When your framework replaces a highlighted element, the step [follows the new one](/docs/interactive-tours#elements-that-re-render).
