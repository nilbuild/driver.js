Each theme is plain CSS on top of the default [checklist](/docs/checklists) styles. Copy its CSS into your stylesheet and pass its class name to the checklist:

```js
import { checklist } from "driver.js/checklist";
import "driver.js/dist/driver.css";
import "driver.js/dist/checklist.css";
import "./checklist-theme.css"; // The CSS you copied

checklist({
  id: "onboarding",
  className: "checklist-gradient",
  items,
}).show();
```

Mix their rules or start your own from one. Every class name is listed in [Theming](/docs/theming#checklist-classes).

## Progress Ring

A ring around the launcher that fills up as items are done, with the number of
items left inside it. The checklist sets `--driver-checklist-progress` to the
progress as a percentage for the ring, `{{remaining}}` puts the count inside it,
and `{{percent}}` shows the percentage in the panel:

<ChecklistSample
  idPrefix="theme-ring"
  bare
  items={items}
  config={{
    className: "checklist-ring",
    completed: ["profile"],
    progressText: "{{percent}}% complete",
    launcherProgressText: "{{remaining}}",
  }}
  client:load
/>

```js
checklist({
  id: "onboarding",
  className: "checklist-ring",
  progressText: "{{percent}}% complete",
  launcherProgressText: "{{remaining}}",
  items,
});
```

<Code code={ringCss} lang="css" theme="monokai" />

## Celebration

A finished state that rewards the user. Once every item is done, the checklist
shows `completeTitle` and `completeDescription`, the launcher shows
`completeLauncherText`, and the CSS turns it green. This demo starts with three
of four items done, so click the last one to see it.

<ChecklistSample
  idPrefix="theme-celebration"
  bare
  items={items}
  config={{
    className: "checklist-celebration",
    completed: ["profile", "tour", "invite"],
    completeTitle: "You're all set! 🎉",
    completeDescription: "Nice work. You're ready to go.",
    completeLauncherText: "All done",
  }}
  client:load
/>

```js
checklist({
  id: "onboarding",
  className: "checklist-celebration",
  completeTitle: "You're all set! 🎉",
  completeDescription: "Nice work. You're ready to go.",
  completeLauncherText: "All done",
  items,
});
```

<Code code={celebrationCss} lang="css" theme="monokai" />

For confetti or a "You did it" modal, use the `onComplete` hook. It fires once
when the last item is done:

```js
checklist({
  id: "onboarding",
  items,
  onComplete: () => confetti(),
});
```
