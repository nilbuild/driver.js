A tour is a list of steps. Each step highlights an element and describes it in a popover. Pass the steps to `driver()` and call `drive()`.

## Animated Tour

The highlight glides from one step to the next by default. Users move with the buttons or the arrow keys, and close with <kbd>Escape</kbd>.

### Animation Duration

`duration` sets how long the move between steps and the fade-in take, in milliseconds. The default is `400`.

<CodeSample
  buttonText={"Fast: 150ms"}
  config={{
    animate: true,
    duration: 150,
    showProgress: true,
  }}
  tour={[
    { element: '.line:nth-child(1)', popover: { title: 'Fast', description: 'The highlight snaps from step to step.', side: "bottom", align: 'start' }},
    { element: '.line:nth-child(5)', popover: { title: 'Duration', description: 'This tour uses 150 milliseconds.', side: "bottom", align: 'start' }},
    { element: '.line:nth-child(11)', popover: { title: 'Done', description: 'Now try the slow one.', side: "top", align: 'start' }},
  ]}
  id={"duration-example-fast"}
  client:load
>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    duration: 150,
    steps: [
      // ...
    ],
  });

  driverObj.drive();
  ```
</CodeSample>

## Static Tour

`animate: false` turns the animation off. The highlight jumps straight to each step.

<CodeSample
  config={{
    animate: false,
  }}
  tour={[
    { element: '#tour-static', popover: { title: 'Static Tour', description: 'No gliding and no fade-in.', side: "left", align: 'start' }},
    { element: '.line:nth-child(5)', popover: { title: 'animate: false', description: 'One option turns the animation off.', side: "bottom", align: 'start' }},
    { element: '.line:nth-child(11)', popover: { title: 'Start the Tour', description: 'Everything else works the same.', side: "top", align: 'start' }},
  ]}
  id={"tour-static"}
  client:load
>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    animate: false,
    steps: [
      // ...
    ],
  });

  driverObj.drive();
  ```
</CodeSample>

## Tour Progress

`showProgress: true` shows the step count in the popover's bottom left corner, as `{{current}} of {{total}}`. Change the text with `progressText`.

<CodeSample
  config={{
    showProgress: true,
    progressText: "Step {{current}} of {{total}}",
  }}
  tour={[
    { element: '#tour-progress-example', popover: { title: 'Progress', description: 'The step count is in the bottom left corner.', side: "left", align: 'start' }},
    { element: '.line:nth-child(5)', popover: { title: 'showProgress', description: 'It is off by default.', side: "bottom", align: 'start' }},
    { element: '.line:nth-child(6)', popover: { title: 'progressText', description: 'A template with the current step and the total.', side: "bottom", align: 'start' }},
  ]}
  id={"tour-progress-example"}
  client:load
>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    showProgress: true,
    progressText: "Step {{current}} of {{total}}",
    steps: [
      // ...
    ],
  });

  driverObj.drive();
  ```
</CodeSample>

Both can be set per step in its `popover` as well.
