Every step and highlight can show a popover next to its element. This page covers where it sits and which buttons it has. To change how it looks, see [Theming](/docs/theming).

## Position

`side` picks the side of the element the popover sits on: `"top"`, `"right"`, `"bottom"` (default) or `"left"`. `align` places it along that side: `"start"` (default), `"center"` or `"end"`.

```js
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

const driverObj = driver();

driverObj.highlight({
  element: "#sample-box",
  popover: {
    title: "Left Start",
    description: "On the left, aligned with the top edge.",
    side: "left",
    align: "start",
  },
});
```

## Buttons

`showButtons` picks the buttons: `"next"`, `"previous"` and `"close"`. A tour shows all three by default. Set it on the driver for every step, or on a step's `popover`.

<div className='flex flex-col gap-1'>
  <CodeSample
    heading={"Buttons"}
    buttonText={"Next and Previous Only"}
    config={{
      showButtons: ['next', 'previous'],
    }}
    tour={[
      { element: '.line:nth-child(5)', popover: { title: 'No Close Button', description: 'Escape and a click on the overlay still close the tour.', side: "bottom", align: 'start' } },
      { element: '.line:nth-child(12)', popover: { title: 'Last Step', description: 'Next reads Done here.', side: "top", align: 'start' } },
    ]}
    id={"buttons-sample"}
    client:load>
    ```js
    import { driver } from "driver.js";
    import "driver.js/dist/driver.css";

    const driverObj = driver({
      showButtons: ["next", "previous"],
      steps: [
        { element: "#search", popover: { title: "Search", description: "Find anything." } },
        { element: "#export", popover: { title: "Export", description: "Download a CSV." } },
      ],
    });

    driverObj.drive();
    ```
  </CodeSample>

- `disableButtons` takes the same values and shows the button greyed out. Previous is disabled on the first step.
- The arrow keys follow the buttons: they do nothing when their button is hidden or disabled. Escape does nothing when the close button is disabled.
- `highlight()` shows no buttons by default. Outside a tour, Next and Previous only do something if you set `onNextClick` and `onPrevClick`.
- A step with [`popover.instruction`](/docs/action-driven-tours#make-the-user-act) keeps the Next button but shows it disabled until the user has done it.

### Change Button Text

`nextBtnText`, `prevBtnText` and `doneBtnText` set the button text, and HTML is allowed. `closeBtnLabel` sets the screen reader label of the close button.

    prevBtnText: '&larr; Back',
    doneBtnText: 'Finish',
    closeBtnLabel: 'Close tour',
  }}
  tour={[
    { element: '.line:nth-child(5)', popover: { title: 'Next', description: 'With an arrow.', side: "bottom", align: 'start' } },
    { element: '.line:nth-child(7)', popover: { title: 'Done', description: 'The last step uses doneBtnText.', side: "bottom", align: 'start' } },

  id={"button-text"}
  client:load>
  ```js

  import "driver.js/dist/driver.css";

  const driverObj = driver({
    nextBtnText: "Next &rarr;",
    prevBtnText: "&larr; Back",
    doneBtnText: "Finish",
    closeBtnLabel: "Close tour",
    steps: [
      // ...
    ],
  });

  driverObj.drive();
  ```
</CodeSample>

### Event Handlers

`onNextClick`, `onPrevClick`, `onCloseClick` and `onDoneClick` run instead of the button's default action. The tour then only moves or ends when you call `moveNext()`, `movePrevious()` or `destroy()`. Set them on the driver for every step, or on a step's `popover`.

`onDoneClick` runs on the last step instead of `onNextClick`, so it tells you the user finished the tour.

<CodeSample
  buttonText={"Show Example"}
  config={{}}
  tour={[
    { element: '.line:nth-child(8)', popover: { title: 'Open Your Console', description: 'Each button logs a line before doing its job.', side: "bottom", align: 'start' } },
    { element: '.line:nth-child(20)', popover: { title: 'Last Step', description: 'Done runs onDoneClick, not onNextClick.', side: "bottom", align: 'start' } },
  ]}
  id={"logger-events"}
  client:load>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    steps: [
      // ...
    ],
    onNextClick: () => {
      console.log("Next clicked");
      driverObj.moveNext();
    },
    onPrevClick: () => {
      console.log("Previous clicked");
      driverObj.movePrevious();
    },
    onCloseClick: () => {
      console.log("Close clicked");
      driverObj.destroy();
    },
    onDoneClick: () => {
      console.log("Done clicked");
      driverObj.destroy();
    },
  });

  driverObj.drive();
  ```
</CodeSample>

`onNextClick` also runs when the step is completed another way: the right arrow key, an overlay click with `overlayClickBehavior: "nextStep"`, [`advanceOn`](/docs/interactive-tours#advance-on-click) or `advance()`. For loading something before the next step, see [Async Steps](/docs/interactive-tours#async-steps).

### Custom Buttons

`onPopoverRender` gets the popover's DOM before it shows, so you can add to it. This adds a button that restarts the tour. The `driver-popover-footer-btn` class gives it the default button look.

<CodeSample
  buttonText={"Run Example"}
  config={{
    showButtons: ['next', 'previous'],
  }}
  tour={[
    { element: '#demo-hook-theme', popover: { title: 'A Fourth Button', description: 'Go on to the next step, then use Go to First.', side: 'left', align: 'start' } },
    { element: '.line:nth-child(12)', popover: { title: 'The Popover DOM', description: 'footerButtons is the container of the Next and Previous buttons.', side: 'bottom', align: 'start' } },
    { element: '.line:nth-child(14)', popover: { title: 'Your Own Handler', description: 'Buttons you add get their own click events.', side: 'bottom', align: 'start' } },
  ]}
  id={"demo-hook-theme"}
  client:load
>
  ```js
  import { driver } from "driver.js";
  import "driver.js/dist/driver.css";

  const driverObj = driver({
    steps: [
      // ...
    ],
    onPopoverRender: popover => {
      const firstButton = document.createElement("button");
      firstButton.innerText = "Go to First";
      firstButton.className = "driver-popover-footer-btn";
      popover.footerButtons.appendChild(firstButton);

      firstButton.addEventListener("click", () => driverObj.drive(0));
    },
  });

  driverObj.drive();
  ```
</CodeSample>

The parts of the popover you can reach are listed in [Theming](/docs/theming#changing-the-popover-dom).
