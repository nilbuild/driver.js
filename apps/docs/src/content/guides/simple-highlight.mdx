`highlight()` shows a single step without a tour. Use it for contextual help: explain a feature, guide a form, or dim the page around one element.

<CodeSample
  id={"highlight-me"}
  buttonText={"Highlight Me"}
  config={{
    popoverClass: "driverjs-theme",
    stagePadding: 4,
  }}
  highlight={{
    element: "#highlight-me",
    popover: {
      side: "bottom",
      title: "This is a title",
      description: "This is a description",
    },
  }}
  client:load
/>

```js
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

const driverObj = driver({
  popoverClass: "driverjs-theme",
  stagePadding: 4,
});

driverObj.highlight({
  element: "#highlight-me",
  popover: {
    side: "bottom",
    title: "This is a title",
    description: "This is a description",
  },
});
```

A highlight popover has no buttons unless you ask for them with `showButtons`. The user closes it with <kbd>Escape</kbd> or a click on the overlay, and your code closes it with `destroy()`. Leave out `popover` to only dim the page around the element.

## Without an Element

Leave out `element` and the popover shows in the middle of the screen, like a modal. The title and description take HTML.

<CodeSample
  id={"show-popover"}
  buttonText={"Show Popover"}
  highlight={{
    popover: {
      description: "<img src='/animated-example.webp' style='height: 202.5px; width: 270px;' /><span style='font-size: 15px; display: block; margin-top: 10px; text-align: center;'>Yet another highlight example.</span>",
    },
  }}
  client:load
/>

```js
driverObj.highlight({
  popover: {
    description:
      "<img src='/welcome.webp' width='270' />" +
      "<p>Yet another highlight example.</p>",
  },
});
```
